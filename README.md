# 📖 Flutter Journal UI

A clean and modern **Journal App UI** built with Flutter.

I recreated this interface to practice building polished mobile layouts in Flutter while focusing on spacing, typography, cards, navigation, and reusable UI components.

## 🎨 About The UI

The design focuses on creating a calm and simple journaling experience where users can:

- 🌅 Start their day with daily reflections
- 📖 Access their personal journal
- 😊 Track their emotions
- ✍️ Create quick journal entries
- 🎯 Set daily intentions
- 📅 Navigate through different days
- 👤 Access their profile
- 📊 View their journal statistics

## 🚀 Features

- Clean and modern mobile UI
- Daily date selector
- Journal cards
- Quick journal section
- Emotion tracking screen
- Bottom navigation
- Floating action button
- Reusable Flutter widgets
- Responsive layout
- Smooth and minimal design

## 🛠️ Built With

- **Flutter**
- **Dart**
- Material Design
